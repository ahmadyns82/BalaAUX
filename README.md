# Bala AUX 🚗🎵

iPhone music player that routes audio through Bluetooth HFP — works with cars that only support hands-free calling (no A2DP music streaming).

## How it works
Uses **CallKit** to trick iOS into routing music through the Bluetooth call channel — same path as a real phone call.

## Features
- 📁 Browse music by folder
- 🎵 Full player with seek, shuffle, repeat
- 🚗 **Bala AUX Mode** — routes audio via Bluetooth HFP/CallKit
- 📱 Lock screen & Control Centre controls
- 🎧 Background playback

## Install
Build via Codemagic → install unsigned IPA via Sideloadly.

## Usage
1. Connect car Bluetooth (calls must work)
2. Open app → Settings → toggle **Bala AUX Mode** ON
3. Play music — audio comes through car speakers
